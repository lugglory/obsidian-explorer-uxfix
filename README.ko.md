# Explorer UX Fix

[English](README.md)

Obsidian 파일 탐색기에서 파일이나 폴더를 꾹 눌러 이름을 바꾼다.

- **파일이나 폴더를 꾹 누르면(기본 0.8초, 설정에서 조절) 이름을 바꾼다.** 이름 자리가 입력 칸으로 바뀌고 이름 전체가 선택된다. 파일 확장자는 그대로 두고 이름만 고친다.
- **Enter를 누르거나 다른 곳을 클릭하면 바꾸고, Esc를 누르면 그대로 둔다.** 한글을 조합하다가 글자를 끝내려고 누른 Enter로는 바뀌지 않는다.
- 이름은 Obsidian 자체 파일 관리 기능으로 바꾸므로, "내부 링크 자동 업데이트" 설정에 따라 이 파일을 가리키는 링크도 함께 바뀐다.
- 쓸 수 없는 글자(`\ / : * ? " < > |`)가 들어 있거나 같은 이름이 이미 있으면 바꾸지 않고 알림으로 알려 준다.
- 누르는 동안 마우스 오른쪽 아래에 편집 아이콘이 왼쪽에서 오른쪽으로 차오른다.
- 누르는 동안 4px 넘게 움직이면 보통 끌어서 옮기기다. 스크롤하거나 창을 바꿔도 취소된다.
- 꾹 누르기가 된 뒤 손을 떼도 파일이 열리거나 폴더가 접히고 펴지지 않는다.
- Ctrl, Shift, Alt, Cmd를 함께 누른 클릭, 다른 마우스 단추, 볼트 맨 위 폴더는 건드리지 않는다.
- 설정은 영어로, Obsidian이 한국어면 한국어로 나온다.
- 데스크톱 전용. Obsidian 1.13 이상이 필요하다.

## 설치

최신 릴리스의 `main.js`, `manifest.json`, `styles.css`를 `<볼트>/.obsidian/plugins/explorer-uxfix/`에 복사하고 설정 → 커뮤니티 플러그인에서 켠다.

## 빌드

```
npm install
npm run build
```
